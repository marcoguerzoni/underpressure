# Under Pressure

Sito del progetto di ricerca **Under Pressure** del Dipartimento DEMS –
Università di Milano-Bicocca, finanziato da Unicredit Foundation.

Sito statico (HTML/CSS/JS, nessun build step), pubblicato con GitHub Pages.

## Pagine
- `index.html` — Home
- `chi-siamo.html` — Il gruppo di ricerca e il DEMS
- `progetto.html` — Il progetto: survey e formazione
- `partecipa.html` — Come partecipare

Contatto: progetto.scuole@unimib.it

## Anteprima locale

Esegui `python3 -m http.server 8000` in questa cartella e apri http://localhost:8000.

## Pubblicazione

Repository: https://github.com/marcoguerzoni/underpressure
